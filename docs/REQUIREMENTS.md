# Digital Album 요구사항 정의서

## 1. 목표
사용자가 사진을 업로드하고 앨범 단위로 정리/공유할 수 있는 웹 서비스를 구축한다.

## 2. 주요 사용자
- 개인 사용자: 가족/여행 사진 정리
- 소규모 그룹: 지인들과 앨범 공유

## 3. 핵심 사용자 시나리오
1. 회원가입 후 로그인한다.
2. 새 앨범을 생성하고 제목/설명을 입력한다.
3. 사진을 업로드하고 캡션/태그를 등록한다.
4. 앨범에서 사진 목록을 조회하고 상세 사진을 본다.
5. 필요 시 사진/앨범을 수정하거나 삭제한다.

## 4. 기능 요구사항

### 4.1 인증
- 이메일/비밀번호 기반 회원가입
- 로그인/로그아웃
- 비밀번호 최소 길이 및 기본 검증

### 4.2 앨범 관리
- 앨범 생성/조회/수정/삭제(CRUD)
- 앨범 소유자만 수정/삭제 가능

### 4.3 사진 관리
- 이미지 파일 업로드(JPG/PNG)
- 사진 목록/상세 조회
- 사진 캡션/태그 수정
- 사진 삭제

### 4.4 공유
- 앨범 공개/비공개 설정
- 공개 앨범 읽기 전용 링크 제공(후속 단계)

## 5. 비기능 요구사항
- 성능: 주요 API 응답 500ms 내(로컬 개발 기준, 파일 업로드 제외)
- 보안: 인증이 필요한 API는 토큰 검증 필수
- 안정성: 업로드 실패 시 사용자에게 명확한 오류 메시지 제공
- 확장성: 스토리지(S3 호환) 교체/확장이 쉬운 구조 유지

## 6. 제약사항
- 초기 MVP에서는 소셜 로그인 제외
- 초기 MVP에서는 동영상 업로드 제외

## 7. 성공 지표(MVP)
- 가입 사용자 10명 이상이 앨범/사진 업로드 흐름을 완료
- 핵심 기능(인증/앨범/사진 CRUD) 수동 QA 통과율 95% 이상
