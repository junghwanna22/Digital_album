# Digital Album 요구사항 정의서

## 1. 목표
사용자가 NAS, OneDrive, FTP 등 외부 스토리지에 저장된 사진을 조회하고 앨범 단위로 정리/공유할 수 있는 웹 서비스를 구축한다.

## 2. 주요 사용자
- 개인 사용자: 가족/여행 사진 정리
- 소규모 그룹: 지인들과 앨범 공유

## 3. 핵심 사용자 시나리오
1. 회원가입 후 로그인한다.
2. 새 앨범을 생성하고 제목/설명을 입력한다.
3. 앨범에 외부 스토리지(NAS/OneDrive/FTP) 폴더를 연동한다.
4. 앨범에서 사진 목록을 조회하고 상세 사진을 본다.
5. 사진에 태그/캡션을 추가하여 메타데이터를 관리한다.

## 4. 기능 요구사항

### 4.1 인증
- 이메일/비밀번호 기반 회원가입
- 로그인/로그아웃
- 비밀번호 최소 길이 및 기본 검증

### 4.2 앨범 관리
- 앨범 생성/조회/수정/삭제(CRUD)
- 앨범 소유자만 수정/삭제 가능
- 앨범에 외부 스토리지 연동 설정

### 4.3 사진 관리 (외부 스토리지 기반)
- **외부 스토리지 연동**
  - NAS (SMB/CIFS 프로토콜)
  - OneDrive (Microsoft Graph API)
  - FTP (표준 FTP 프로토콜)
- **사진 목록 조회** (읽기 전용)
  - 연동된 폴더 내 이미지 자동 스캔
  - JPG, PNG, WEBP 등 주요 형식 지원
- **메타데이터 관리** (로컬 DB에 저장)
  - 사진별 캡션/태그 추가
  - 사진 순서 정렬
  - 메타데이터만 DB에서 관리 (실제 파일은 외부 스토리지에 유지)
- **사진 상세 조회**
  - 사진 미리보기 (썸네일, 원본)
  - 메타데이터 표시 (캡션, 태그, 촬영 정보)

### 4.4 공유
- 앨범 공개/비공개 설정
- 공개 앨범 읽기 전용 링크 제공 (후속 단계)

## 5. 비기능 요구사항
- **성능**: 주요 API 응답 500ms 내(로컬 개발 기준, 외부 스토리지 조회 제외)
- **보안**: 
  - 인증이 필요한 API는 토큰 검증 필수
  - 외부 스토리지 자격증명은 암호화하여 저장
  - 사용자는 자신이 연동한 스토리지만 접근 가능
- **안정성**: 스토리지 연결 실패 시 사용자에게 명확한 오류 메시지 제공
- **확장성**: 스토리지 어댑터 패턴으로 새로운 외부 스토리지 추가 용이

## 6. 제약사항
- 초기 MVP에서는 소셜 로그인 제외
- 초기 MVP에서는 사진 직접 업로드 제외 (외부 스토리지만 지원)
- 사진 메타데이터는 로컬 DB에만 저장 (원본 파일 수정 불가)
- 사진 삭제는 메타데이터만 삭제 (실제 파일은 외부 스토리지에서 유지)

## 7. 성공 지표(MVP)
- 가입 사용자 10명 이상이 외부 스토리지 연동 및 앨범/사진 조회 흐름을 완료
- 핵심 기능(인증/앨범/외부 스토리지 연동/사진 조회) 수동 QA 통과율 95% 이상
- NAS, OneDrive, FTP 중 최소 1가지 이상 정상 동작 확인
