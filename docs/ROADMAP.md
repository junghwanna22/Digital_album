# Digital Album Roadmap

## Phase 1 - Planning (Week 1)
- 사용자 시나리오 정리
- 필수 기능(MVP) 확정
- 와이어프레임 작성

## Phase 2 - MVP Build (Weeks 2-4)
- 인증(회원가입/로그인)
- 앨범 생성/수정/삭제
- 사진 업로드/조회

## Phase 3 - Polish (Week 5)
- 검색/태그 필터
- 반응형 UI 보완
- 에러 핸들링 및 로깅 강화

## Phase 4 - Release Prep (Week 6)
- 테스트 자동화
- 배포 파이프라인 구성
- 베타 사용자 피드백 반영
