# MVP 범위 정의

## 포함(In Scope)
- 이메일 회원가입/로그인
- 내 앨범 목록
- 앨범 생성/수정/삭제
- 사진 업로드/조회/삭제
- 기본 태그/캡션 관리

## 제외(Out of Scope)
- 소셜 로그인
- 고급 검색(유사 이미지, 위치 기반)
- 앨범 협업 편집 권한
- 모바일 네이티브 앱

## 화면 목록(초안)
1. 로그인/회원가입 페이지
2. 대시보드(내 앨범 리스트)
3. 앨범 상세(사진 그리드)
4. 사진 업로드 모달/페이지

## 릴리스 기준
- 핵심 사용자 시나리오 1~4 완료 가능
- 치명/주요 버그 없음
- 기본 CI 파이프라인 통과
